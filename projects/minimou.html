Minimou

A Paint app you draw with your hand. A Kinect tracks it above a table, and the canvas is projected in front of you.

C++, Python, Kinect, Docker. Source on GitHub

Overview

Built in one week for the school's open day. Touching the table draws, hovering stops, and buttons only trigger when you make a pressing motion, so passing over them does nothing.

Features

  • Undo and redo
  • Color palette and brush size
  • An image brush that stamps EPITA's logo
  • Clear the canvas
  • Send the drawing by email: a popup asks for the address, which you type on the keyboard
