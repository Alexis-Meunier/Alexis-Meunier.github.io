PulMetrix

A web app that segments the lungs on DICOM chest X-rays and measures how asymmetric they are.

Python, FastAPI, React, Docker. Source on GitHub

Overview

A group medical imaging project. You load a chest X-ray in DICOM format, the app segments both lungs, then compares them. A FastAPI backend does the image processing and a React frontend shows the results.

Features

  • Automatic segmentation with TVAC, an active contour based on total variation
  • Semi-manual segmentation by region growing from points you click
  • Asymmetry analysis between the left and right lung
  • Documented REST API with Swagger
  • Frontend and backend started together with Docker Compose
