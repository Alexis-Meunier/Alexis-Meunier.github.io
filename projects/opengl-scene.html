OpenGL Shader Scene

A real-time scene built with geometry, tessellation and compute shaders: terrain, water, grass, bloom and an exploding bunny.

C++20, OpenGL 4.5, GLSL. Source on GitHub

Overview

A school project to go past vertex and fragment shaders. Each effect uses a different stage of the OpenGL 4.5 pipeline, and they all run together in one scene with a day/night cycle.

Features

  • Terrain from a heightmap made by a compute shader, with detail added by tessellation
  • Water waves animated by a compute shader, driven by wind speed and direction
  • Grass blades built by a geometry shader
  • Skybox and sun that follow the time of day
  • Moving emissive lights with a compute-shader bloom
  • A bunny mesh blown apart by compute and geometry shaders
  • Tessellation levels, wind and time of day you can change while running

Demo
