Sheet Music Recognition

Finds the notes on a score. Prototyped in Python, then rewritten in C++ and benchmarked against it.

C++, Python, OpenCV. Source on GitHub

Overview

A school project in two steps: a Python prototype, then a C++ version to simulate the move from prototype to real implementation. It is evaluated against the real notes of 10 scores.

Features

  • Detection of the notes on a score image
  • Evaluation against ground-truth .agnostic files
  • Benchmark option to time a single recognition or the full evaluation
  • Python prototype: about 0.07 s per image. C++ version: under 0.01 s
