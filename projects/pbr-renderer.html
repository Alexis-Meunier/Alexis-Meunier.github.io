PBR Renderer

A physically based renderer in the browser, showing 25 spheres with different metallicity and roughness.

TypeScript, WebGL2. Source on GitHub

Overview

Built on a starter provided by the course. Use the interface to set each sphere's material and to display every intermediate step of the pipeline, so each stage can be checked on its own.

Features

  • Point lights, Lambertian diffuse and Cook-Torrance GGX specular
  • Tone mapping from HDR to LDR
  • Diffuse and specular image-based lighting from RGBM environment maps
  • Specular lighting from the pre-computed textures or from a probe generated at startup
  • Controls for metallicity, roughness and the displayed step

Demo

Needs a browser with WebGL2. Open the demo in its own tab.
