Numba Fast Marching

A web app that runs the fast marching method on an image, in plain Python and with Numba, and compares the times.

Python, Numba, Streamlit, PostgreSQL, Docker. Source on GitHub

Overview

A group project to measure what Numba gains over plain Python. You upload an image and a mask, the app runs the fast marching method from the mask with both versions, and shows the two results side by side with their run times.

Features

  • Fast marching method in plain Python and compiled with Numba
  • Upload images and masks, and reuse earlier uploads
  • Bar chart of the time saved by Numba
  • Database page with upload counts and last and average run times
  • API, PostgreSQL and Streamlit frontend in three Docker containers
