Real-time Movement Filter

A GStreamer plugin that highlights moving objects in red. The CUDA version runs the whole pipeline on the GPU.

C++, CUDA, GStreamer. Source on GitHub

Overview

The filter learns the background of a fixed camera, compares each frame with it, cleans the result and paints the moving areas in red. A plain C++ version is kept as a sequential reference.

Features

  • Per-pixel background model with 5 reservoirs, then difference, noise removal and hysteresis thresholding
  • One GPU thread per pixel, with state buffers allocated once and reused
  • Separable erosion and dilation
  • Hysteresis reconstruction on 32x32 tiles in shared memory, repeated until it converges
  • Hardcoded thresholds, so results depend on the video

Demo

Run it

nix develop
cmake -S . -B build --preset release -D USE_CUDA=ON
cmake --build build
export GST_PLUGIN_PATH=$(pwd)
ln -sf ./build/libgstcudafilter-cpp.so libgstcudafilter.so
gst-launch-1.0 uridecodebin uri=file://$(pwd)/input.mp4 ! videoconvert ! "video/x-raw, format=(string)RGB" ! cudafilter ! videoconvert ! fpsdisplaysink
