Cel Shader

A toon shader for .obj models, with a movable light and an adjustable black outline.

C++, OpenGL, GLSL. Source on GitHub

Overview

Built with a teammate (Zarvork) for a school project to learn OpenGL. It loads .obj models, with or without textures, and renders them with discrete light bands and a black outline, like a cartoon.

The test model is the 12140 Skull v3 L2 by jesusterradagomez, from Sketchfab.

Features

  • Cel / toon shading with banded lighting
  • Colour interpolation you can switch between linear and logarithmic
  • Outline thickness you can change while running
  • Free-fly camera and a light you can move around the model
  • Toon shading can be turned off for models without textures

Demo

Run it

cmake -S . -B build
cmake --build build
./build/CelShading 0 objects skull.obj 2
