CPU Path Tracer

A path tracer written from scratch in C++20. It renders on the CPU and writes a PPM image.

C++20. Source on GitHub

Overview

Built during EPITA's IMAGE major, together with Roman Miralves, after learning how path tracing works. Scenes are described in code by creating objects and setting their positions.

Features

  • Spheres, triangles and complex meshes read from .obj files, sped up with a BVH
  • Blobs (implicit surfaces)
  • Glass, image textures, uniform textures and procedural textures (sky and wood, from 3D Perlin noise)
  • Point lights and circle (spot) lights

Demo

Run it

make
./main render.ppm
